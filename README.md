# The-U.S-Sales-Analysis-for-The-Pacesetter-Woman-Conglomerate-
The data for this analysis was retrieved from kaggle.com. It was cleaned and analysed with Microsoft Excel tool, the visualization was also designed on Excel. It focused on the client's business problems and answered questions geared towards helping the organisation make informed decisions. Lastly, insights from the analysis were summarised clearly and concisely to interpret and communicate the results of the analysis.
